Standalone AllDebrid

Turns your debrid library into Jellyfin media folders. Nothing is downloaded: the plugin writes playable links and Jellyfin streams straight from your account.

Jellyfin stores plugin settings as plain XML on disk. Anyone who can read the config directory can read this key. Protect the host or the disk.
The address players use to reach this Jellyfin server, for example http://192.168.1.20:8096. Leave empty to use the address Jellyfin reports; in Docker that is often the container's own and unreachable from a player.
