Jellyfin setup

Four steps, one key, and one link you copy from your LeLibrary setup page.

Watch the tour

One minute: what it does, the four install steps, and what it will not do.

Supported Real-Debrid, AllDebrid, Premiumize later

Jellyfin 12 only. The plugin will not load on 10.x.

1. Add the plugin repository

Dashboard → Plugins → Repositories → +. Give it any name and this URL:

https://lelibrary.github.io/LeLibrary-Jellyfin/manifest.json

2. Install and restart

Plugins → Catalog → LeLibrary → Install. Restart Jellyfin when it asks. Updates arrive here too; nothing to download by hand.

3. Copy your LeLibrary link

On your LeLibrary setup page, open the Jellyfin card and copy the setup link. It looks like https://lelibrary.uk/<your-setup> and it is personal: anyone with it can read your library.

4. Fill in the plugin settings

Debrid providerTorBox for now
Debrid API keyyour own key, from your provider's account page
LeLibrary URLthe link from step 3 - a trailing /manifest.json is accepted too
Server URLthe address your players use, e.g. http://192.168.1.20:8096
Sync every6 hours by default

Press Test key, then Run sync now. The first sync creates the TorBox Movies and TorBox Series libraries and fills them - tens of thousands of titles in about two minutes.

In Docker the server reports its container address, which players cannot reach. Always set Server URL on a containerised install.

Everyday use

  • It syncs on startup and every six hours, or whenever you press Run sync now.
  • Adding a title in LeLibrary and syncing puts it in Jellyfin. Removing it from LeLibrary takes it out on the next sync.
  • Watched state and resume points are kept per item, because item ids are derived from a stable key.
  • Changing your debrid key re-signs everything on the next sync without touching what you have watched.

What it will not do

Not a mountNothing outside Jellyfin can read this library. For Infuse, rclone or an *arr stack pointed at the same files, use a folder/mount tool instead.
No downloaderNothing is fetched until something plays, and nothing is kept afterwards.
No search-on-demandOnly what is already in your debrid account appears.
Stored releases onlyCompressed or encrypted archives are left out rather than added as something that will not play.
No external subtitle filesEmbedded subtitles work; sidecar subtitle files are not written.

When something is wrong

  • Test key says the key was rejected: check it on your provider's page. Nothing in the library changes on a failed key.
  • The library is empty: press Run sync now and read the message. A failed sync never deletes anything.
  • Playback says there are no compatible streams: check Server URL is the address players use.
  • Logs: Dashboard → Logs, look for LeLibrary.

Your key stays yours

LeLibrary never sees your debrid key: the plugin talks to your provider directly. Jellyfin stores plugin settings as plain XML on disk, so protect the config directory. The LeLibrary setup link is written into Jellyfin and gives read access to your library - treat it like a password.
