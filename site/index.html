LeLibrary debrid plugins for Jellyfin

Connect Jellyfin directly to TorBox, Real-Debrid, AllDebrid or Premiumize. Jellyfin handles metadata and artwork. The provider plugins do not require a LeLibrary account or setup token.

In Jellyfin, add this repository under Dashboard → Plugins → Repositories:

https://lelibrary.github.io/LeLibrary-Jellyfin/manifest.json

Install the plugin for your provider, restart Jellyfin, enter your provider key in its settings and save before testing or syncing.

Provider plugins require Jellyfin 12.4 or newer. Live provider account testing, automatic removal and migration from the legacy plugin are not yet complete.

The separate legacy LeLibrary plugin remains available for existing users and still requires a LeLibrary setup.
