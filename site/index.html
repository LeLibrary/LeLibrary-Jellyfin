Your debrid library,
inside Jellyfin.

LeLibrary already decides which titles belong in your library and what they are called. This plugin puts that same library into Jellyfin: real posters, real seasons, real playback, and nothing downloaded until you press play.

Status

Version 0.1

TorBox Real-Debrid next

Built and tested against Jellyfin 12. Not for 10.x.

Library

Appears in seconds

Items live in Jellyfin's database, so there is no file scan. 39,000 titles in about two minutes.

Playback

Links minted on play

Every play asks for a fresh link, so nothing you watch can be replayed from an old URL.

Install

  1. Dashboard → Plugins → Repositories → +, and add this URL: https://lelibrary.github.io/LeLibrary-Jellyfin/manifest.json
  2. Plugins → Catalog → LeLibrary → Install, then restart Jellyfin.
  3. Open the plugin's settings, paste your LeLibrary setup link and your own debrid key, then press Test key and Run sync now.
  4. The plugin creates TorBox Movies and TorBox Series itself. Nothing to add by hand.

What it will not do

Not a mountNothing outside Jellyfin can read this library. For Infuse, rclone or an *arr stack, use a folder/mount tool instead.
No downloaderNothing is fetched until something plays, and nothing is kept afterwards.
No search-on-demandOnly what is already in your debrid account appears. Discovery is the LeLibrary addon's job.
Stored releases onlyA compressed or encrypted archive is left out rather than added as something that will not play.

Your key stays yours

The plugin asks for your debrid key directly and never sends it to LeLibrary. Jellyfin stores plugin settings as plain XML on disk, so anyone who can read the config directory can read it - protect the host or the disk. The LeLibrary setup link is written into Jellyfin, so treat it like a password.
